查看程序逻辑可知，elf执行接受第一个参数，然后以root权限运行sh文件，并且传递参数

[ "$1" = "flag" ] && exit 2
[ $1 = "flag" ] && chmod +s /bin/bash

关键在于这两行

1.字分割(与bash版本有关)

**==$1会进行字分割以及文件名扩展，"$1"则不会
例如，如果我给定$1为flag （注意flag后有空格），则"$1"则为flag （空格），从而判等不成立，而$1则会因为字分割，从而导致$1=flag，$2=空格，从而判等为bash加上s位
