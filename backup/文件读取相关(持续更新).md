
## 1.wc命令
	 wc（word count）命令是Linux中常用于计算文件的行数、字数和字节数的工具。
	 可利用读取文件内容
```
		 wc --files0-form “/etc/passwd”
```
## 2.sed命令
	   **sed** 是一种强大的流编辑器，用于处理文本数据。它以行为单位执行操作，如添加、删除、替换和更多，使得它成为自动化文本编辑的理想工具。
	   利用
```
		   sed -n 'p' /etc/passwd 
			   -n参数 安静模式只输出被sed处理过的
```
## 3.sd命令（类似sed命令）
	  利用
```
		  sd -p a b /etc/passwd
			  -p指定预览模式不会对文件做出修改，打印出替换后的结果到终端
```

## 9.cp命令

cp命令在创建文件时会保留源文件的属组和权限，但是如果覆盖文件则是保留覆盖文件的属组和权限
```
		touch /tmp/test
		chmod 777 /tmp/test
		cp password.txt /tmp/test 
```
同样也可以直接cp 文件  /dev/stdout
```
		cp password.txt /dev/stdout
```
